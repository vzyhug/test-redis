# CÁC LỆNH THIẾT KẾ DỮ LIỆU REDIS
# Nguồn: redis-data-design.md
# Môi trường: Redis 7+, một primary; dùng trong redis-cli hoặc RedisInsight.
# Redis không cần CREATE TABLE: key được tạo khi ghi dữ liệu lần đầu.
# Chỉ là danh mục lệnh theo từng nghiệp vụ, KHÔNG chạy toàn bộ file lần lượt.
# Chọn khối cần dùng và thay tất cả <THAM_SO> trước khi chạy.
# Không chạy file này bằng PowerShell/bash: đây là lệnh Redis, không phải lệnh shell.
# Không chứa cấu hình kết nối, secret thật hoặc code worker Firestore.
#
# QUY ƯỚC THAM SỐ
# u001                  : user_id ví dụ, thay bằng uid thật trong Firestore.
# <SID_HASH>            : SHA-256 của secret cookie do backend sinh; không phải secret.
# <SESSION_REF>         : HMAC-SHA256 đầy đủ trên sid, dùng khóa tham chiếu riêng.
# <IDENTIFIER_DIGEST>   : HMAC-SHA256 định danh đăng nhập đã chuẩn hóa.
# <IP_DIGEST>           : HMAC-SHA256 IP, không dùng email/IP thô trong key.
# <OPERATION_ID>        : ID ổn định cho một thao tác login, giữ nguyên khi retry nội bộ.
# <EVENT_ID>            : UUID duy nhất cho một sự kiện, giữ nguyên khi gửi lại.
# <SOURCE_EPOCH>        : UUID thế hệ dữ liệu Redis.
# <REQUEST_ID>          : ID theo dõi request.
# <NOW_MS>              : thời gian hiện tại tính bằng milliseconds UTC.
# <ACCOUNT_CREATED_MS>  : thời điểm tạo tài khoản gốc.
# <PROFILE_UPDATED_MS>  : thời điểm cập nhật hồ sơ gốc.
# <COUNTING_STARTED_MS> : mốc bắt đầu ghi nhận thống kê chung, không reset khi retry.
# <ABSOLUTE_MS>         : thời điểm tạo phiên + 604800000 (7 ngày), cố định suốt phiên.
# <EXPIRES_MS>          : min(NOW_MS + 1800000, ABSOLUTE_MS), idle timeout 30 phút.
# <ONLINE_UNTIL_MS>     : min(NOW_MS + 300000, EXPIRES_MS), online trong 5 phút.
# Các thời điểm số nguyên được thay vào không có dấu < > và không có dấu phân cách.
# Các giá trị UA/IP bên dưới chỉ là dữ liệu mẫu.

# 2. THÔNG TIN TÀI KHOẢN - HASH, CACHE 15 PHÚT
# Dữ liệu gốc lấy từ Firestore. Cache này không quyết định quyền đăng nhập.
MULTI
HSET auth:account:u001 user_id u001 username hung display_name "Duy Hưng" email hung@example.com status active created_at <ACCOUNT_CREATED_MS> profile_updated_at <PROFILE_UPDATED_MS> cached_at <NOW_MS>

EXEC

# Lệnh DEL trên là ví dụ độc lập; không chạy nếu đang muốn giữ cache mẫu vừa tạo.
